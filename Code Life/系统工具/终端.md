# 终端工具- Ghostty

1. 下载官网 https://ghostty.org/docs/install/binary#ubuntu
2. linux 下载命令
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/mkasberg/ghostty-ubuntu/HEAD/install.sh)"
```
3. 安装配置文件
```bash
mkdir -p ~/.config/ghostty
nano ~/.config/ghostty/config


# 设置为默认终端
gsettings set org.gnome.desktop.default-applications.terminal exec ghostty

gsettings set org.gnome.desktop.default-applications.terminal exec-arg ''

gsettings get org.gnome.desktop.default-applications.terminal exec
'ghostty'
```

```ini
# 字体（Neovim 开发推荐 Nerd Font）
font-family = JetBrainsMono Nerd Font
font-size = 14

# 主题
theme = catppuccin-mocha

# 透明度（可选）
background-opacity = 0.95

# 开启真彩色（Neovim 必须）
term = xterm-256color
```

4. 主题文件失效
![[Pasted image 20260327234611.png]]
	1. 解决方法 
```bash
# 克隆 Ghostty 主题仓库
git clone https://github.com/catppuccin/ghostty.git /tmp/catppuccin-ghostty

# 创建主题目录
mkdir -p ~/.config/ghostty/themes

# 复制主题文件
cp /tmp/catppuccin-ghostty/themes/* ~/.config/ghostty/themes/

# 创建所需文件
cp ~/.config/ghostty/themes/catppuccin-mocha.conf ~/.config/ghostty/themes/catppuccin-mocha
```
4. 由于终端配置的文字字体不生效因此有以下解决办法
`vim ~/.config/fontconfig/fonts.conf`
输入
```xml
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "fonts.dtd">
<fontconfig>
    <!-- 1. 当软件请求普通的 monospace 时，优先喂给它 SemiBold (字重 180) -->
    <match target="pattern">
        <test name="prgname"><string>ghostty</string></test>
        <test name="family"><string>monospace</string></test>
        <test name="weight" compare="less_eq"><int>100</int></test> <!-- Regular 级别 -->
        <edit name="family" mode="prepend" binding="strong">
            <string>Maple Mono NF CN</string>
        </edit>
        <edit name="weight" mode="prepend" binding="strong">
            <int>180</int> <!-- 180 在系统里代表 SemiBold -->
        </edit>
    </match>

    <!-- 2. 当软件请求加粗的 monospace 时，优先喂给它 ExtraBold (字重 205) -->
    <match target="pattern">
        <test name="prgname"><string>ghostty</string></test>
        <test name="family"><string>monospace</string></test>
        <test name="weight" compare="greater"><int>100</int></test> <!-- Bold 级别 -->
        <edit name="family" mode="prepend" binding="strong">
            <string>Maple Mono NF CN</string>
        </edit>
        <edit name="weight" mode="prepend" binding="strong">
            <int>205</int> <!-- 205 在系统里代表 ExtraBold -->
        </edit>
    </match>
</fontconfig>
```
在运行
`fc-cache -frv`
之后在ghostty的配置文件中加入：
```ini
font-family = monospace

font-size = 11

theme = Catppuccin Macchiato
background-opacity = 1.0

cursor-style = bar
cursor-style-blink = true

window-padding-x = 10
window-padding-y = 10
```
