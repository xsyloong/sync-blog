### 依赖倒置原则

*定义：* 高层模块不能直接依赖底层模块，二者都应该依赖于抽象。抽象不依赖细节，细节依赖抽象。

*原始设计：*
```mermaid
classDiagram
    direction LR
    class Shop {
        -weChatPay: WeChatPay
        -aliPay: AliPay
        +checkout(amount, payType)
    }
    class WeChatPay {
        +pay(amount)
    }
    class AliPay {
        +doPay(amount)
    }

    Shop --|> WeChatPay : 直接依赖
    Shop --|> AliPay : 直接依赖
```

*使用依赖倒置重构：*

```mermaid
classDiagram
    direction LR

    class Shop {
        +checkout(amount, paymentGateway: IPay)
    }

    class IPay {
        <<Interface>>
        +pay(amount)
    }

    class WeChatPay {
        +pay(amount)
    }

    class AliPay {
        +pay(amount)
    }

    Shop ..> IPay : 依赖于抽象
    WeChatPay ..|> IPay : 实现接口
    AliPay ..|> IPay : 实现接口
```
