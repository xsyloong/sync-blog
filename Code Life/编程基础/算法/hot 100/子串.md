## [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)
### 解法

```c++
class Solution {

public:
    int subarraySum(vector<int>& nums, int k) {
        int sum = 0,res= 0 ;
        unordered_map<int, int> map;// 前缀和 - 次数
        map[0] = 1;
        for (int i = 0;i < nums.size();i++){
            sum += nums[i];
            if (map.find(sum - k) != map.end()) {
                res += map[sum - k];
            }
            map[sum]++;
        }
        return res;
    }
};
```
